# T4 thinking-mode run at 512 tokens: 2026-09-03

## Outcome

This run is accepted as validation of the T4 execution and trace-export
pipeline. All three generations reached EOS, passed the known-answer checks,
contained 20–29 reasoning spans, and stayed below 1.46 GiB peak allocated GPU
memory.

The run's original receiver-head manifest is **not accepted as a scientific
head-discovery result**. Inspection showed that its leading heads primarily
attended from the trailing EOS token to the terminal `Answer:` span. That is an
answer/EOS effect rather than evidence of an earlier thought anchor.

## EOS confound in the original manifest

For each of the original manifest's leading heads, the largest vertical score
belonged to the final `Answer:` sentence. The reducer included the trailing EOS
token as a future query, so it measured EOS reading the final answer. The
original top candidate `L27:H4` must therefore not be described as a thought
anchor receiver head.

As a diagnostic only, removing the terminal-answer column changed the top
candidate to `L23:H6`. Pairwise top-20 overlaps fell to 6, 5, and 1 heads, with
only one head shared across all three traces. This post-hoc result remains
provisional because EOS also contributed to the averages of earlier spans.

## Correction and next stage

Commit `499d594` excludes the terminal answer from candidate spans and removes
the trailing EOS query from every vertical-attention average. The next Colab
stage will recapture corrected scores and run teacher-forced causal sentence
suppression with matched controls in the same bounded run.
