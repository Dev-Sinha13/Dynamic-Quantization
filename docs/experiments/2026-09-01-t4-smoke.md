# T4 smoke run: 2026-09-01

## Outcome

The first Qwen3-0.6B Colab run validated the GPU trace-export pipeline, but it is
**not an accepted receiver-head discovery result**. All three decoded responses
end mid-sentence before giving a final answer. This is consistent with the
original notebook reaching its 128-token generation cap while Qwen thinking
mode was enabled.

The artifacts should therefore be treated as a failed-but-informative smoke
test. They must not be used to support causal or cache-compression claims.

## Receiver-head diagnostic

The generated manifest ranked layer 27, query head 1 first, with a reported
stability of `0.9886`. That aggregate value is not sufficient evidence of a
stable receiver head. Direct per-trace top-20 comparisons gave:

| Trace pair | Shared top-20 heads | Jaccard similarity |
|---|---:|---:|
| `math-000` / `math-001` | 3 | 0.081 |
| `math-000` / `math-002` | 0 | 0.000 |
| `math-001` / `math-002` | 2 | 0.053 |

No head appeared in the top 20 of all three traces. The different sentence
counts and incomplete outputs also make raw cross-trace kurtosis difficult to
interpret. Head-ranking methodology should be revisited after complete traces
are available.

## Corrections made before rerun

1. Disable Qwen thinking mode for bounded, concise reasoning traces.
2. Increase the generation allowance from 128 to 192 tokens.
3. Reject a generation that reaches the cap without an EOS token.
4. Remove decoded special tokens from sentence segmentation.
5. Correct the Qwen3-0.6B head dimension in memory estimates from 64 to 128.
6. Persist GPU identity, software versions, generated text, token counts, and
   peak GPU allocation in `run-summary.json`.

These corrections landed in commits `363bec7` and `1d43000`.

## Acceptance criteria for the next run

- All three samples end normally and contain the expected numerical answer.
- `run-summary.json` is present in the downloaded ZIP.
- No sample reaches `max_new_tokens` without EOS.
- Each trace has at least three meaningful sentence spans.
- GPU peak allocation and software versions are recorded.

Only after these checks pass should the run be expanded to a larger prompt set
or used to select heads for causal intervention.
